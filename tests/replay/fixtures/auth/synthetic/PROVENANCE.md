# Authentication fixture provenance

These response bodies are hand-authored synthetic examples for the current
client's QR-login request and response handling. They were not captured from
Tuya or a Tuya account. All codes, IDs, tokens, endpoints, and times are
fabricated; the example endpoint uses the reserved `example.invalid` domain.
The fixture shape is test input only and does not verify a private Tuya route
or its wire contract.
