The report cannot be independently reproduced or inspected from this repository. The documented list API types `start_time` and `end_time` as `Long`; the
existing public `QueryDevicesRequest` exposes them as strings. The library sends
them through its custom encrypted parameter path. The maintainer reports
successful account testing, but there is no recorded exchange to review how
those timestamps are encoded in that flow.

The checked-in OpenAPI subset documents only `QueryDevices`; its generated result type is used by that method, and CI checks for generated-file drift. It does not define private route contracts. The account-test report supports that the maintainer exercised the flows successfully, but it is not a captured exchange or a reproducible route-level record. Keep the private routes out of the provider schema until a matching current official wire specification or a sanitized live exchange with provenance is available. Record request and response fields, statuses, redactions, and provenance. Keep unsupported and placeholder operations out of the published provider schema.
