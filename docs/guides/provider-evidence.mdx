# Provider evidence

The guides label behavior as **provider-documented** when it is described in
Tuya's published documentation and **implementation-derived** when it reflects
the client's observed request or response handling. Implementation-derived
details can vary by account, region, device, or service version.

There are no sanitized account captures in this repository. Checked-in replay
examples are synthetic and show how this client handles a paired exchange; they
do not establish provider behavior.

See the [device query guide](../device-list),
[authentication guide](../authentication), and
[Go API reference](https://pkg.go.dev/github.com/portpowered/go-tuya/pkg/tuya)
for current usage and operation details.
