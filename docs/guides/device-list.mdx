# Query devices

See the [generated route reference](../../openapi/device-management/getDeviceList)
for query fields and the response shape.

Tuya documents [`GET /v1.0/devices`](https://developer.tuya.com/en/docs/cloud/7ccd629a6c?id=Kconjb15xpvd3)
for listing devices and status. Set `page_no` and `page_size`; optional filters
include device IDs, product ID, schema, cursor, and time range.

The library method with this matching path is `DevicesService.QueryDevices`:

```go
devices, err := session.DevicesService.QueryDevices(ctx, tuya.QueryDevicesRequest{
    PageNo:   1,
    PageSize: 20,
    Schema:   appSchema,
})
if err != nil {
    return err
}

fmt.Printf("Received %d of %d devices\n", len(devices.Devices), devices.Total)
```

The result exposes `Devices`, `Total`, and `LastID`. Device fields can include
`LocalKey`, so select fields rather than logging the full response. Pass decimal
timestamp strings for `StartTime` and `EndTime`; Tuya's reference types these as
integers, while the public Go request uses strings.

Tuya documents this route and selected response fields. The Device Sharing
signing and encryption used by this client are implementation-derived.
