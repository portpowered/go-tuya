# Regions and endpoints

The client defaults to the US Device Sharing cloud endpoint. Use
`WithRegion` to select a built-in region, or set custom cloud and
authentication endpoints when creating the reusable client:

```go
client, err := tuya.NewClient(
    tuya.WithCloudAPIURL(cloudURL),
    tuya.WithAuthenticationURL(authenticationURL),
)
if err != nil {
    return err
}
```

Operations depend on the account, region, and device. Check a device's
specification before sending commands. The client does not control devices on
the local network.

See the [Go API reference](https://pkg.go.dev/github.com/portpowered/go-tuya/pkg/tuya)
for the available options and services.
