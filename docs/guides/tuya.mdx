# Tuya service notes

The client defaults to the US cloud endpoint. Select a built-in region with
`tuya.WithRegion`, or provide custom cloud and authentication endpoints with
`tuya.WithCloudAPIURL` and `tuya.WithAuthenticationURL` when creating the
reusable client.

Available operations depend on the account, region, and device. Command codes
and values are device-specific; inspect a device's specification before
sending commands. The library does not control devices on the local network.
Some declared surfaces remain placeholders, including the scene service and
`Unload`. Check the [Go API reference](https://pkg.go.dev/github.com/portpowered/go-tuya/pkg/tuya)
and the root README's supported-operation list before depending on an
operation.

Compare implementation behavior with Tuya's [Device Sharing SDK](https://github.com/tuya/tuya-device-sharing-sdk)
and [cloud API reference](https://developer.tuya.com/en/docs/cloud/api-reference).
For the limits of checked-in evidence, see
[provider evidence](../provider-evidence).
